# docs/spine (One-Spine Phase 1a)

Inventory artifacts for `docs/ONE_SPINE_PLAN.md` (PR #217). Docs and tests only: nothing here moves, edits or archives code.

- `orchestrators.csv`: every git-tracked `.py` whose filename contains `orchestrat` (70 on main @ 0b8ae22; the spine tooling in docs/spine/ and tests/spine/ is excluded). Columns: path, sha256 and size of the **git blob** (index content, so CRLF/LF checkouts give identical output), imported_by count + up to 3 examples, top-level import style (`import *`, `path-based` = sys.path / spec_from_file_location / runpy / `__import__`, or `normal`), **proposed** fate (core / plugin / shim / archive) and `duplicate_of` for byte-identical copies. Fates are heuristic proposals for travis to review; nothing is archived without a GO per batch (D2).
- `build_orchestrators_csv.py`: regenerates the CSV with `python docs/spine/build_orchestrators_csv.py` (ast only, imports nothing; `--out PATH` writes elsewhere). `tests/spine/test_orchestrators_csv.py` regenerates it to a temp dir and asserts it is byte-identical to the committed CSV.
- `tests/spine/test_import_graph.py`: the Phase 1b critical-path skeleton. Statically parses every tracked `.py` and asserts each repo-local import resolves to a file or package. Imports already broken on main are frozen in `tests/spine/import_graph_baseline.txt`; the test fails only on new breaks. It must stay green before ANY archive batch.

Note: imported_by counts only static `import`/`from` statements. Path-based loads are flagged in import_style but not counted, so review those rows by hand.
- `tests/spine/test_no_archive_importers.py`: Phase 1b acceptance test. Asserts no production module imports an archive-verdict file from `orchestrators.csv`, statically or via a dotted-name/path string (importlib, routing tables). The 5 dynamic edges already on main are listed in `KNOWN_DYNAMIC`; their targets (`realai/orchestration/{realai,legacy,unified}_orchestrator.py`, `abilities/hive_orchestrator.py`) must be rewired or re-verdicted before their archive batch.
